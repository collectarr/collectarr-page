## Choose your kind

Open the navigation menu and select **Libraries**. Choose Music, Book, Comic, Manga, Movie, TV, Anime, Game or Board Game. The top bar names the active kind and uses its accent.

## Add your first entry

1. Choose **Add from Core**, or the kind's Add button in the library toolbar. Music calls this **Add Albums**.
2. Search for an item. Core search needs a reachable metadata server.
3. Inspect the result, including its edition and format.
4. Use the add action to create a local library entry.
5. Select the new entry to show it in the inspector.

If there is no suitable catalog result, choose **Add Manually**. Enter the title and applicable details, then save.

## Make it yours

Open **Edit**. Enter personal information such as status, location, quantity, condition, purchase information or notes. Catalog information describes the collectible; personal information describes your copy. Save applies the changes; Cancel discards them.

Use the bottom collection tabs for named collections. Use collection status for ownership versus wish-list state. These are separate concepts.

## Importing an existing collection

Start with a small sample and check the import preview, delimiter and field mapping. Back up existing data before a large import or bulk operation. See [Import/export](../import-export/) and [Backup](../backup-sync/).
