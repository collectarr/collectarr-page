## Open the editor

Select an entry and choose **Edit** in the inspector. The editor shows kind-specific catalog tabs and supported Personal, Custom Fields, Covers, My Images and Links sections.

![Music editor with album metadata](../../../assets/screenshots/editor.png)

The dialog keeps its top edge in place when changing tabs. Scroll within longer sections. Save uses the active kind's accent.

## Catalog versus personal

| Catalog | Personal |
| --- | --- |
| Title, edition, contributors, release details | Status, index, quantity, location |
| Tracks, public artwork and format | Condition, purchase details, notes and tracking |
| What the collectible is | Information about your own copy |

Personal changes do not propose a Core correction. Where available, a correction flow compares catalog data and lets you review it before submission.

## Saving and navigation

**Save** applies changes. **Cancel** leaves the saved entry unchanged. Read the unsaved-change confirmation before discarding edits. Previous/Next move between entries where offered in the edit flow.

## Pick lists and multiple values

Some controls allow free text plus existing vocabulary; others provide a strict choice list. The picker chooses a value; the manage action maintains the underlying list. Add multi-value entries separately rather than concatenating them into one string.

## Batch editing

Select the intended entries and open the available batch edit action. Apply only the fields you want to change and check the selected count. Batch editing may offer a different set of fields from the single-entry editor.

For discs, tracks and credit scope, see [Music](../kinds/music/).
