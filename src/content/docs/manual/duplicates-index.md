## Find Duplicates

Open **Find Duplicates** and choose the matching criteria offered for the current kind. Inspect each candidate group using the available actions. Back returns to the library.

A candidate is not automatically an error: editions can share titles and independent copies can be intentional. Compare identifiers, edition, condition and personal information before removing anything.

## Re-assign Index Numbers

Open **Re-assign Index Numbers**. Choose the intended scope, ordering and starting number with the offered controls. Review the affected count before applying.

An index is your library numbering, not a barcode, catalog identifier, disc number or volume number.

## Before maintenance

Back up before a large reassignment or removal. For missing entries, first clear collection, search, folder and status restrictions. See [Backup](../backup-sync/).
