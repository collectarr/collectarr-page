## Import Data

Choose a supported file and use the offered delimiter/format and field mapping. Inspect the preview and active kind. Try a small sample first, especially for dates and multi-value fields.

Only fields offered by the importer are importable. A field appearing in edit/export does not imply import support.

## CSV/TXT export

Open the CSV/TXT export action, choose scope and columns, then the offered delimiter/format controls. Save and inspect the file in your destination program.

Raw values and summaries differ. In Music, Disc Formats lists distinct formats; Format Summary describes their complete combination. Choose the appropriate representation.

Flat exports are useful reports, but do not include every local image, setting or tracking record. They are not full database backups.

## Integration export

The integration exporter provides supported formats such as XML for structured workflows. Review format and scope; a CSV field mapping is not interchangeable with another export contract.

## Print to PDF

Open **Print to PDF**, choose report options and inspect the preview before printing/saving. A report is a presentation, not an editable database copy.

Use your browser's Print action to save a manual chapter as PDF.
