## Choose columns

Open the column chooser from the toolbar. Choose fields and arrange the selected fields there. Column headers themselves are not a drag-to-reorder surface.

Resize a column at its boundary where the view exposes a handle. Automatic column sizing and wrapping can affect displayed widths; review those preferences in Appearance.

## Sorting

Open the sort selector, choose fields and order, and apply. The first field is the primary comparison; later fields break ties. Set ascending/descending as appropriate.

Available sort fields are intentional. A multi-value field can be groupable/filterable without having a useful single sort value.

## Music values and summaries

**Format Summary** describes the disc combination. **Disc Format** contains the distinct actual formats. Group/filter using Disc Format rather than text matching a summary.

**Earliest Disc Recording Date** and **Latest Disc Recording Date** are explicit scalar sorts. A year-only date uses the beginning of its year for earliest ordering and the end for latest ordering; a month-only date similarly covers its month.

## Presentation

Settings → Appearance controls wrapping, automatic widths, collection indicators and edit icons. These change presentation, not stored values. See [Settings](../settings/).
