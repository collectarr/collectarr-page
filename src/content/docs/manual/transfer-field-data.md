## Configure the operation

1. Open **Transfer Field Data**.
2. Choose the entry scope: all or an available selection/filter scope.
3. Choose source and compatible destination fields.
4. Choose Copy or Move.
5. Set how to handle existing destination values.
6. Review the affected count and apply.

## Modes

**Copy** preserves the source. **Move** writes the destination and clears the transferred source. Do not choose Move when you still need the original field.

## Conflicts

- **Skip** keeps an existing target unchanged.
- **Overwrite** replaces it.
- **Append** adds after existing text and is offered for text fields.

Only supported transferable fields are offered. Editable/exportable does not automatically mean transferable.

## First run

Back up, then try a small selection and inspect its entries before transferring a large scope. Reset clears configuration; Cancel leaves the data unchanged.
