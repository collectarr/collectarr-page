## Core search

**Add from Core** returns to the library and opens the active kind's add flow. Search using its supported fields or identifiers, inspect a result and add it to your library.

The add flow offers **Search**, **Barcode** and **Manual** controls. In Music, search for the artist/title or use a barcode. Inspect the actual result before adding: a matching title alone does not confirm the format or edition. A catalog number is an edition field; this guide does not assume a separate catalog-number search tab.

Adding creates a local entry. The Core reference records provenance; you can subsequently edit the entry independently.

## Manual entry

Choose **Add Manually**. Enter what you know. A partial date can contain a year, year/month or complete date; do not invent a day for an unknown date. Keep copy-specific notes in personal fields or [custom fields](../custom-fields/).

## Multiple copies

Quantity can represent identical copies. Independent entries are useful when copies have different condition, location, purchase information or loan history. Duplicating an entry creates an independent local record.

## Linking and proposals

The **Link** tool associates an existing local entry with an appropriate Core match. Review the edition before applying a link; it is different from adding another copy.

Where the flow offers a proposal/correction action, review the catalog changes before submitting. Personal data is not proposed as shared catalog metadata. See [Editing](../editing/).
