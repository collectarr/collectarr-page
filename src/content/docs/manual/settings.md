## Settings sections

| Section | Controls |
| --- | --- |
| Connection | Metadata server, personal sync, pairing and history |
| Libraries | Library customization |
| Appearance | Theme, workspace layout, inspector, display and localization |
| Proposals | Catalog proposal settings/status |
| Data | Backup, restore and maintenance |
| Account | Account and sign-in |
| Logs | Diagnostic messages |

Open **Settings** in navigation. Its layout adapts to window width.

## Appearance

Review application skin, details-panel template, backdrop/back-cover display, wrapping, automatic column widths, status indicators and edit icons.

Localization controls change display currency, number/date/time formats and timezone. They do not convert amounts. Sort-title/name preferences can affect ordering or display; inspect them when names appear under unexpected letters.

Auto-capitalization follows the chosen method/exceptions. Review it before applying it to established names.

## External search

eBay settings control visibility, status scope, placement and search choices where offered. These are external links, not guaranteed stored valuations.

## Pre-fill Settings

Choose supported defaults for new entries. Check the resulting add dialog before saving. A changed default does not edit existing entries.

## Keyboard shortcuts

Open **Help → Keyboard Shortcuts** for the actual application reference. Key behavior can depend on focus/platform; text-field editing keys differ from library actions. Manual search is independent of the app's library search.
