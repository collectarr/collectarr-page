Collectarr offers rich customization options to tailor the interface, theme, data defaults, localization formats, and keyboard workflows to your personal collecting preferences.

Open **Settings** from the main drawer menu (or click the gear icon in the toolbar).

## Settings Sections Overview

| Section | Description and Primary Controls |
| :--- | :--- |
| **Appearance** | Theme (Dark/Light), accent colors, cover styling, custom platform icons, typography, localization, and date/currency formats |
| **Pre-fill Settings** | Automatic default values (Location/Box, Condition, Tags, Store) for newly added items |
| **Data** | Automatic daily backups, manual database backups, restoration manager, cover cache maintenance, and vacuum |
| **Updates** | In-app software updater: check for, download, and install new versions on the Stable, Beta, or Nightly channel |
| **Connection** | Collectarr Core metadata server, personal synchronization pairing, and sync history |
| **Proposals** | Status and history of submitted metadata contributions and revisions sent to Core |
| **Account** | User profile credentials and authentication status |
| **Logs** | Diagnostic activity logs, sync event history, and error reports |

## Appearance and Layout

The **Appearance** tab controls how Collectarr looks and behaves across all views and panels.

![Collectarr Appearance Settings](../../../assets/screenshots/settings-appearance.png)

### 1. Theme and Skin
- **Theme Mode**: Switch between reference **Dark Mode**, **Light Mode**, or follow **System Default**. Main menu and header chrome maintain clear contrast while content areas reflect your chosen theme.
- **Accent Color**: Personalize the highlight accent used across buttons, tabs, selection bands, and active icons.
- **Custom Platform Icons**: Load your own custom SVG or raster platform artwork from your local files to customize platform badges in Games.
- **Show Trailer Videos**: Toggle embedded YouTube video trailers in the Games details panel.

### 2. Localization & Formats
- **Primary Currency**: Choose your local currency ($ USD, € EUR, £ GBP, ¥ JPY, kr. DKK, lei, etc.) and currency symbol formatting (e.g. `US$ 12.50` vs `$12.50`).
- **Date Display & Entry**: Choose from 17 date display formats (such as `YYYY-MM-DD`, `DD/MM/YYYY`, `MM/DD/YYYY`, or localized long dates).
- **Number Formats**: Choose from 6 standard numeral formats (e.g. `1,234.56` or `1.234,56`).
- **Articles Ignore List**: Customize leading grammatical articles (`The`, `A`, `An`, `Le`, `La`, `Das`, `Der`) bypassed during alphabetical sorting.

## Pre-fill Settings

Save time when cataloging new acquisitions by configuring **Pre-fill Settings**:

![Collectarr Pre-fill Settings](../../../assets/screenshots/prefill-settings.png)

- **Default Storage Location / Box**: Automatically assign newly added items to your main shelf or longbox.
- **Default Condition**: Pre-select your typical acquisition grade (e.g., *Near Mint* or *9.8*).
- **Default Tags**: Automatically attach common tags.
- **Default Purchase Store**: Pre-fill your favorite local shop or online seller.

## Keyboard Shortcuts

Press `F1` or open **Main Menu → Keyboard Shortcuts** to view available shortcuts:

| Shortcut | Action |
| :--- | :--- |
| `Ctrl+N` / `Cmd+N` | Open Add Items dialog |
| `Ctrl+E` / `Cmd+E` or `Enter` | Edit selected item |
| `Ctrl+S` / `Cmd+S` | Save editor changes |
| `Escape` | Close dialog or clear active search |
| `Ctrl+K` / `Cmd+K` | Focus live search box |
| `Ctrl+A` | Select all items in current library view (or select field text) |
| `Enter` (in multi-value fields) | Commit value and keep caret for next value |
| `Ctrl + Mouse Wheel` | Zoom UI scale in and out |
