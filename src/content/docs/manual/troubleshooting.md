## An entry is missing

Clear search, alphabet restriction, selected group and status filter. Check collection tab and kind before adding the entry again.

## Core or Find Online fails

Check Connection settings, server address and network. Try a known title/identifier. Image retrieval and search can fail independently; try another image or local upload.

## Names are split into folders

Inspect spelling, whitespace and vocabulary. Manage Pick Lists provides the relevant maintenance actions. Music artist credits and role credits are separate concepts; see [Music](../kinds/music/).

## Column widths look different

Check automatic widths/wrapping in Appearance. Resize at the column boundary; use the chooser to change order.

## Data differs on another device

Check personal sync, pairing and history. Core sign-in alone does not synchronize personal entries. In a browser, also check profile and origin.

## Fonts differ

The app can load user-supplied fonts where supported, otherwise it uses a fallback. This site uses system fonts and does not distribute licensed CLZ fonts.

## Report a problem

Record app version, platform, kind, reproducible steps and error. Inspect Settings → Logs. Remove private notes, tokens and account details before sharing captures/logs.

Use the [Collectarr issue tracker](https://github.com/collectarr/collectarr-app/issues) and include a minimal example with the expected result.
