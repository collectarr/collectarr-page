## Named collections

Use the collection tabs along the bottom to switch named collections for the active kind. Open **Manage Collections** to maintain them and their order. Collections are useful for separating, for example, a listening room from storage.

## Manage collections

Create or rename a collection using the manager. Drag its rows to reorder the bottom tabs. At least one collection must remain. Deleting a non-empty collection asks you to choose another collection for its entries and confirm the move; it does not silently discard those entries.

## Status is separate

The main toolbar's status dropdown filters the library. The edit dialog's status field changes the entry. Use an in-collection status for ownership and a wish-list status for something you want to acquire; choose other offered statuses for your workflow.

Changing status does not itself mean assigning the entry to another named collection.

## Organization choices

- **Collections**: named sets of entries.
- **Group By**: folders derived from values such as artist or genre.
- **User folders**: explicit organization.
- **Smart Lists**: saved rules selecting matching entries.

Rule-based results can change when field values change. Use collections for stable named organization.

## Missing entries

The active collection, status filter, search, alphabet letter and selected folder work together. Return to the all-items folder and clear restrictions before concluding an entry is missing or adding it again.
