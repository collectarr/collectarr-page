One guide for all your collections. Read the common chapters, then open the kind-specific sections for fields and workflows that differ.

Collectarr is a **local-first collection manager**. Your entries live in a local database. Core supplies shared catalog metadata; optional personal sync is a separate service. Adding a Core item creates an independently editable entry in your own library.

This guide describes the current beta application and uses English interface labels. Screenshots show fictional demonstration data. Controls can differ with the active kind, deployment and window width.

## Using this guide

Use Search at the top to search every chapter. The left sidebar lists topics; the right outline jumps within an article. On a narrow screen, open Menu for the chapters. Your browser's Print command can save an article as PDF.

In Collectarr, **Help → User Manual** opens this site in your browser at the current kind's chapter. **Keyboard Shortcuts** opens the application's shortcut reference.
