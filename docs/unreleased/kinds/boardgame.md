## Edition and components

Check title, edition language and region where offered. Copy-specific fields include component condition/completeness, missing-pieces notes, Sleeved, Custom insert, Painted miniatures and storage notes.

Keep these personal rather than altering shared catalog descriptions. Copies with different completeness can need separate entries.

## Plays and loans

Record plays with board-game play sessions. Tracking describes your use of the game; catalog data describes the game itself.

See [Loan Manager](../../loans-statistics/) and [My Images](../../images/) for lending and component photos.
