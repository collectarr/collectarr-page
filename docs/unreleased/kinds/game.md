## Platform and copy

Check platform, region and edition. The same title on another platform can be a different collectible.

Entry fields include completeness, Has box, Has manual, Core region and supported valuation data such as PriceCharting ID and Value locked. Use these to describe your copy/configuration.

## Valuation and play

A displayed market value is not a guaranteed sale price. Keep purchases/sales in their personal fields. Use game tracking for play/progress.

Use offered platform groups for browsing. See [Statistics](../../loans-statistics/) for interpreting totals.
